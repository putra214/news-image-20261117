THE WORLD IN A DAY — a one-page newspaper image summing up Tuesday 17 November 2026: 43 stories from 6 continents. Three lead stories get large illustrations and headlines; the 10 biggest stories each get a large illustration and a country map; a world map marks every story at its true coordinates. Every story is verified news of that day, from Kerch Bridge and Bahrain to Cyclone Akvan and the Leonid meteor peak.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies the `entry.png` beside it to the output directory, byte for byte, every run.
